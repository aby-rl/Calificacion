# Regresión no lineal
En este proyecto se trabaja con el archivo “iempo de Entrega.csv”, donde se encuentra información para 432 actividades entregadas en un semestre de la clase de cierta Universidad. En dicha materia, cada semana se entregan actividades y la bandeja de entrega se cierra cada domingo a medianoche. Con esto se busca verificar la hipótesis de que entre más cerca de la hora de cierre de la bandeja se entrega la tarea, peor la calificación en la misma. 

La base de datos cuenta con la siguiente información:
- “Tiempo”. Tiempo restante para que se cerrara la bandeja, en horas. Es decir, un 1 indica que entregaron la actividad el domingo a las 11:00 p.m., y un 48 indica que entregaron la actividad 48 horas antes del domingo a medianoche.
- “Calificacion”. Calificación obtenida, en una escala entre el 0 y el 110.
